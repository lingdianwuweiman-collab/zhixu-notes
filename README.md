# 知序 · 学习笔记网站

一个无需安装、无需服务器的本地学习记录网站。双击 `index.html` 即可运行。

## 两个界面

1. **启动页**：中心是「开始学习」按钮；背景中流动着励志短句与可点击的 AI、机器学习、深度学习资源网址。鼠标停在页面上可暂停弹幕，点击网址将在新标签页打开。
2. **知识树页**：点击「开始学习」后进入原有的知识树和笔记功能。页面底部的「已验证的学习资源」会记录启动页中的网址，可新增、手动删除或点击「检查链接」清理浏览器无法连接的网址；资源变更会同步到启动页。

## 已实现功能

- 树状知识首页：建立顶级分类与无限级子分支，点击分支即可创建或打开笔记。
- 富文本记录：正文、粗体、斜体、列表、待办、一级至三级标题、图片和链接。
- 章节折叠：点击正文中的一级标题，或右侧文章结构里的一级标题，可折叠该标题下的所有内容，直到下一个一级标题。
- 后期整理：标签、标题/正文/标签全文搜索、收藏、回收站、最近编辑、字数统计、复习待办入口、HTML 导出。
- 右键管理：在知识树节点上右键可「添加子节点」「重命名文件夹」或「删除节点」（文件节点右键为「移至回收站」），删除的笔记可在回收站恢复。
- 整体备份：一键导出全部笔记为 JSON 文件，随时导入恢复，防止浏览器数据意外丢失。
- 云端同步：通过 JSONBin.io 将全部笔记备份到云端，记住 Bin 网址即可在任何设备恢复；手动上传和下载，下载前确认覆盖并自动保存一份本地恢复备份。
- 自动保存：所有笔记保存在当前浏览器的 LocalStorage 中；离线可用。

## 使用建议

1. 双击 `index.html`，在首页点击「＋」创建第一条知识分支。
2. 点击某个分支会打开笔记，使用工具栏插入各级标题及图片。
3. 重要内容加入标签或收藏，之后可从左侧搜索快速找到。

> 浏览器本地数据不会跨浏览器自动同步，且可能随浏览器数据清理而丢失。建议双保险：定期点击左侧「导出备份」保存 JSON 文件，并在「云端同步」中配置 JSONBin.io 云端备份。

## 云端保存与下载

1. 打开「云端同步」，填入 JSONBin.io 的 Master API Key。第一次上传时 Bin ID 留空。
2. 点击「上传到云端」，成功后保留生成的 Bin ID 或云端网址。以后每次上传都覆盖这同一份云端内容，下载始终读取其最新内容，操作前会确认覆盖。
3. 在另一台设备打开网站，填入相同的 API Key 和 Bin ID（云端网址会自动填入 ID），点击「从云端下载」，确认后恢复全部笔记、目录及资源。
4. 下载前的本地数据可在云端窗口点击「导出覆盖前备份」取出，再用侧栏「导入备份」恢复。

API Key 只保存在当前浏览器，不包含在云端网址里。关闭页面不会自动上传；编辑完成后请主动上传。网络、权限或容量错误会显示在窗口中，失败不会显示上传成功。

### 云端一致性核对

- 离开编辑器、切换笔记、导出和上传之前，立即保存最新编辑；勾选状态也会保存。
- 上传后检查接口返回的数据，再禁用缓存读取同一 Bin 的最新内容；两次核对均一致才提示成功。更新已有 Bin 时启用历史版本。
- 如果核对失败，保留本地笔记和已创建的 Bin ID，显示具体错误，不应继续下载覆盖。
- 回归检查：在项目目录运行 `node cloud-sync.test.cjs`，覆盖编辑后立即切换、实际接口响应结构、上传下载一致性、恢复备份和取消下载。

云端窗口仅提供「上传到云端」和「从云端下载」两个主要操作；已有存储 ID 会自动沿用，不会因清空输入框而新建另一份云端存储。

### 大笔记自动压缩

JSONBin 免费账户的单条记录上限是 100KB。超过阈值的笔记会无损压缩后保存到原来的同一 Bin，下载时自动还原，并与上传前的内容核对。旧的未压缩云端数据仍可读取；导出的本地 JSON 备份也保持原格式。

如果压缩后的数据仍超限（例如含有较多大图片），上传前会显示原始和压缩后的大小，本地笔记及旧云端数据不会因这次超限而更改。压缩和还原需要支持 CompressionStream / DecompressionStream 的浏览器。

重命名文件夹：在左侧知识树或首页地图的文件夹上右键，选择「重命名文件夹」，输入名称后点击保存（也可按 Enter）。名称立即保存在本地，之后上传云端时一并保存。
