# 知序 · 学习笔记网站

一个无需安装、无需服务器的本地学习记录网站。双击 `index.html` 即可运行。

## 两个界面

1. **启动页**：中心是「开始学习」按钮；背景中流动着励志短句与可点击的 AI、机器学习、深度学习资源网址。鼠标停在页面上可暂停弹幕，点击网址将在新标签页打开。
2. **知识树页**：点击「开始学习」后进入原有的知识树和笔记功能。页面底部的「已验证的学习资源」会记录启动页中的网址，可新增、手动删除或点击「检查链接」清理浏览器无法连接的网址；资源变更会同步到启动页。

## 已实现功能

- 树状知识首页：建立顶级分类与无限级子分支，点击分支即可创建或打开笔记。
- 富文本记录：正文、粗体、斜体、列表、待办、一级至三级标题、图片和链接。
- 章节折叠：点击正文中的一级标题，或右侧文章结构里的一级标题，可折叠该标题下的所有内容，直到下一个一级标题。
- 后期整理：标签、标题/正文/标签全文搜索、收藏、回收站、最近编辑、字数统计、复习待办入口、HTML 导出。
- 右键管理：在知识树节点上右键可「添加子节点」「重命名文件夹」或「删除节点」（文件节点右键为「移至回收站」），删除的笔记可在回收站恢复。
- 整体备份：一键导出全部笔记为 JSON 文件，随时导入恢复，防止浏览器数据意外丢失。
- 本地目录备份：手动导出及修改后的自动备份写入用户授权的 `BeiFeng` 文件夹。
- 自动保存：所有笔记保存在当前浏览器的 LocalStorage 中；离线可用。

## 使用建议

1. 双击 `index.html`，在首页点击「＋」创建第一条知识分支。
2. 点击某个分支会打开笔记，使用工具栏插入各级标题及图片。
3. 重要内容加入标签或收藏，之后可从左侧搜索快速找到。

## 本地 BeiFeng 备份

云端同步已暂停，页面不再提供云端入口，也不会因旧的 `#bin=...` 网址自动打开设置或联网同步。

1. 在 Chrome 或 Edge 中点击「导出备份」，选择项目文件夹 `E:\Study\Chatgpt`，程序会使用其中的 `BeiFeng` 子文件夹；也可以直接选择已有的 `BeiFeng`。
2. 浏览器首次使用时需要用户授权写入目录。目录句柄保存在本机 IndexedDB，之后沿用；若浏览器要求重新授权，点击「导出备份」即可重新允许。打开网站时不会弹出授权框。
3. 手动导出生成带本地日期、时间的 JSON 文件。每次打开网站使用一个带时间的自动备份文件，修改后持续更新；没有数据变更时不重复导出，展开和收起文件夹不触发备份。
4. 有数据变更后约一秒自动写入备份；返回地图时等待写入完成，切走页面时补存。浏览器可能在关闭标签页或退出进程时中断异步写文件，因此提前自动写入；尚未完成的任务会记住，下一次打开且目录权限有效时补存。不能保证关闭后还能继续运行。
5. 可以通过「选择备份文件夹」更换目录。取消选择、授权失效或写文件失败时，本地笔记仍保留，侧栏会显示待备份状态，不会假报成功。
6. 不支持目录写入的浏览器仍可普通下载 JSON，但需手动移入 `BeiFeng`，也不能自动导出到指定目录。

所有备份 JSON 都包含完整笔记、文件夹和学习资源，可用「导入备份」恢复。浏览器本地数据不会跨设备同步，清理网站数据也会清除保存的目录句柄。

文件夹重命名：在左侧知识树或首页地图的文件夹上右键，选择「重命名文件夹」，输入名称后点击保存或按 Enter。

验证：`node local-backup.test.cjs`。
